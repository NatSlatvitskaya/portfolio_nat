# Портфолио Наташи

Этот проект представляет собой главный экран (hero-секцию) сайта-портфолио, разработанный по предоставленному дизайну.

## Спецификации дизайна
1. **Визуальные элементы**:
   - Фоновое видео: `images/fire-bg.mp4` (на весь экран `100vh`, зацикленное, автовоспроизведение, без звука, `object-fit: cover`).
   - Центральный аватар: `.avatar-wrapper` с картинкой `images/avatar.png` шириной `658px`.
2. **Сетка**: 12-колончатая сетка (Stretch; Margin 20px; Gutter 16px).
3. **Шрифты**: Гарнитура *SF UI Display*.
   - «Все проекты» — текстовая кнопка (36px, semibold, акцентный цвет).
   - «6 лет опыта» — статичный текст (36px, semibold, акцентный цвет).
   - «Привет, Я — Наташа {графический и бренд-дизайнер}» — статичный текст (28px, regular, акцентный цвет).
4. **Цветовая палитра**:
   - Акцентный цвет текста: `#00E6A3`
   - Черный фон: `#242424`
5. **Тени и скругления**:
   - Внешние скругления: `24px`
   - Внутренние плашки: `12px`
   - Смещение тени (drop shadow) под обложками кейсов: `x: -30px`, `y: 20px`, `Blur: 30px`, цвет `#000000` с прозрачностью `25%`.
